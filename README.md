# マイインテグリティ（My Integrity）

自分の「譲れない核となる価値観」を見つけるためのセルフワークアプリです。

## 概要

3つのステップを通じて、あなたのインテグリティ（真摯さ・一貫性）の核となる価値観を特定します。

1. **Step 1：価値観を選ぶ** — 50個の価値観キーワードから直感で8〜15個を選択
2. **Step 2：エピソード分析** — 「最高の瞬間」と「最高の怒り」を振り返る
3. **Step 3：トーナメント** — 2つずつ比較して最終的に3つに絞り込む

## 技術スタック

- React 18
- Vite 5
- GitHub Pages

## ローカル開発

```bash
npm install
npm run dev
```

## デプロイ

`main` ブランチにプッシュすると、GitHub Actions で自動的に GitHub Pages にデプロイされます。
